// approach

How I secure a website on AWS

Network

Isolated VPC

Public and private subnets, so only the web tier faces the internet.

Firewall

Tight security groups

Only ports 80/443 are public. SSH is limited to trusted IPs.

Access

Least-privilege IAM

Scoped roles and policies, MFA on accounts, no shared root use.

Data

HTTPS everywhere

Encrypted traffic with a TLS certificate on the site.

Visibility

Logging & monitoring

CloudTrail records account activity, GuardDuty flags suspicious behavior.

Hosts

Hardened Linux server

Updated packages, minimal services, key-based SSH login.

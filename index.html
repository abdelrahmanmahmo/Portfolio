// 02. methodology

Cloud Defense Blueprint

The six pillars I apply across every AWS architecture to guarantee depth in defense.

01 / PERIMETER

VPC Network Isolation

Multi-tier segmentation. Workloads stay strictly in private subnets with controlled egress via NAT.

02 / FIREWALL

Micro-Segmentation

Stateful Security Groups and stateless NACLs allowing only exact port traffic (80/443). Zero default access.

03 / IDENTITY

Least-Privilege IAM

Scoped policies, short-lived STS role assumption, compulsory MFA, and permanent retirement of root credentials.

04 / ENCRYPTION

Data Protection (KMS & TLS)

End-to-end HTTPS for in-transit data and AWS KMS-managed customer keys for at-rest storage and databases.

05 / TELEMETRY

Active Threat Detection

Multi-region CloudTrail combined with GuardDuty ML models analyzing DNS, VPC Flow, and API events 24/7.

06 / COMPLIANCE

Host & OS Hardening

Clean Linux baselines, automated patch cycles, SSH keys only through Bastion tunneling, and disabled root SSH.
